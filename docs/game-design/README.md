**Status:** Living design record, not a claim that the systems are implemented.

## Decision language
- **Approved / established:** Explicitly selected or repeatedly confirmed by the project owner.
- **Working:** Discussed or provisionally adopted, subject to revision.
- **Open:** Not yet determined.
- **Implemented:** Verified in the repository as code or assets. A design entry alone is not implementation.

The fictional histories of coercive research, warfare, institutional abuse and mass atrocities are worldbuilding. Historical references for educational content should be accurate and separately sourced. The site is a prototype, not a finished MMO.
